E-COMMERCE EXAMPLE

Website Visitor + Product Viewed

Website Visitor + Product Viewed + Price/Value doubt → User Intent: Evaluation → Problem: Price/Value objection → Investigation: value/quality communication → Creative Direction: Value/Benefits/Proof → Format: UGC or Demo → Message: product ki value/quality explain karo → CTA: Shop Now → KPI: Purchase/CPA/ROAS.

REAL ESTATE EXAMPLE

Website Visitor + Project Details Viewed

Website Visitor + Project Details Viewed + Configuration doubt → User Intent: Consideration → Problem: Configuration information gap → Investigation: verified project details/message match → Creative Direction: Information + Proof/Objection Handling → Format: Floor Plan/Walkthrough/FAQ → Message: verified configuration + project details → CTA: Get Price Details / Book Site Visit → KPI: Qualified Lead / Cost per Qualified Lead / Site Visit.
