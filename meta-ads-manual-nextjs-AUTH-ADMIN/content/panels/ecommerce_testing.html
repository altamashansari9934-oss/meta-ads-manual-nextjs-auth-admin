01

E-commerce Mein Creative Testing Kya Hota Hai?

Creative testing ka matlab sirf multiple ads chala kar dekhna nahi hai. Purpose ye samajhna hai ki kaunsa Hook, Angle, Visual, Offer, Format ya Message customer ko attention se purchase tak le jaane mein help kar raha hai.

Creative testing ka focus: attention se purchase tak customer kis cheez par respond kar raha hai?
Problem→ Hypothesis→ Control→ Variant→ One Main Change→ Data→ Funnel Diagnosis→ Learning→ Next Test
02

Creative Ke Main Parts

Hook

Ad ke first 1–3 seconds ya first visual/line jo attention grab karta hai.

Angle

Product ko kis reason se present kar rahe ho: price, quality, result, convenience, problem, etc.

Visual

Ad mein kya dikh raha hai: product, person, demo, before/after, UGC, etc.

Format

Static image, video, UGC, carousel, etc.

Offer

Purchase karne ka extra reason: discount, bundle, free shipping, limited offer, etc.

Proof

Trust build karne wali cheez: reviews, ratings, testimonials, real customer use, etc.

CTA

Call to Action: customer ko kya action lena hai, jaise Shop Now.

03

Control vs Variant

Control

Current/reference creative jiske against comparison hota hai.

Variant

Control ka new version jisme ek main change test kiya jaata hai.

Ek test mein ek MAIN variable change karo, jitna practical ho.

Isse result ka reason samajhna easier hota hai.

04

E-commerce Testing Flow

Problem→ Hypothesis→ Control→ Variant→ One Main Change→ Data→ Funnel Diagnosis→ Learning→ Next Test
1

Problem identify karo

Sabse pehle funnel mein actual problem ya drop identify karo.

2

Hypothesis banao

Problem ke possible reason ka logical guess banao.

3

Control set karo

Current/reference creative ko comparison base rakho.

4

Variant banao

Control ka new version banao jisme focused change ho.

5

One Main Change

Jitna practical ho ek main variable isolate karke test karo.

6

Data dekho

Result ko relevant funnel stage ke context mein compare karo.

7

Funnel diagnose karo

Drop creative, post-click, offer/product, delivery ya tracking side par hai ye identify karo.

8

Learning nikalo

Result se kya signal mila, usko next test ke decision mein use karo.

9

Next test banao

Learning ke basis par next focused question test karo.

05

E-commerce Funnel

Impressions CTR Link CTR Landing Page View View Content Add to Cart Initiate Checkout Purchase Revenue ROAS
Basic Diagnosis Rule: Har problem ka answer “new creative banao” nahi hota. Pehle identify karo funnel mein drop kahan hai. Phir decide karo problem creative, post-click, offer/product, delivery ya tracking side par hai.
06

E-commerce Metrics — Simple Meaning

MetricSimple Meaning
ImpressionsAd kitni baar dikhaya gaya.
CTRClick-Through Rate: ad dekhne walon mein se kitne logon ne click kiya.
Link CTRSpecifically website/landing page link par click karne ka rate.
Landing Page ViewClick ke baad page actually load/view hua.
View ContentCustomer ne product/content page dekha.
Add to Cart (ATC)Product cart mein add kiya.
Initiate Checkout (IC)Customer checkout process start karta hai.
PurchaseActual order complete hua.
CVRConversion Rate: visitors/clicks mein se kitne purchase karte hain.
CPACost Per Acquisition: ek purchase lane ka average ad cost.
AOVAverage Order Value: ek order ki average value.
ROASReturn on Ad Spend: ad spend ke against kitni revenue aayi.
CACCustomer Acquisition Cost: ek customer acquire karne ka cost.
FrequencyAverage number of times same person ne ad dekha.
07

Video Creative Timeline Diagnosis

0–3 secHook

Attention capture. Yahan drop hai to opening investigate karo.

3–5 secPromise / Reason to Continue

Hook ke baad customer ko reason milna chahiye ki video continue kare.

5–10 secValue / Proof / Product

Product benefit, demo, proof ya useful information.

10 sec+Deeper Explanation

Extra details only when useful; unnecessary filler avoid karo.

EndCTA

Clear next action do: Shop Now, Buy Now, View Product, etc.

08

Master Rule

Metric dekho→ Funnel stage identify karo→ Drop locate karo→ Possible reasons list karo→ Relevant area diagnose karo→ One main variable test karo→ Result compare karo→ Learning nikalo
